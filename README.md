# Portofolio Profesional - Muhammad Fikri Arsyad

Website Portofolio Profesional karya Muhammad Fikri Arsyad — dikembangkan menggunakan **React**, **Vite**, **Tailwind CSS**, dan **Lucide React**.

## 🚀 Fitur Utama
- **Hero & Interactive CV Modal**: Tampilan depan bersih dengan fitur preview CV interaktif dan tombol unduh.
- **About Me**: Profil ringkas dan spesialisasi keahlian.
- **Skills**: Keahlian utama di bidang AI Design, AI Engineering, dan Web Design.
- **Projects Showcase**: Portofolio proyek digital interaktif dengan slider gambar & link proyek.
- **Work Experience**: Rekam jejak pengalaman profesional.
- **Tools**: Perangkat & tools yang digunakan sehari-hari.
- **Contact**: Akses komunikasi langsung via WhatsApp dan Email.
- **Scroll Reveal Animations**: Animasi kemunculan interaktif saat melakukan scroll.

## 🛠️ Perangkat & Teknologi
- **Framework & Build Tool:** React, Vite
- **Styling:** Tailwind CSS, Lucide Icons
- **Deployment:** Vercel / GitHub

## 💻 Menjalankan Secara Lokal
```bash
# Clone repositori
git clone https://github.com/arsyad122804-design/portofolilo.git

# Masuk ke direktori
cd portofolilo

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```
